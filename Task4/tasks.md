# Крупные задачи по системам

## АБС

- Создать модель депозитных продуктов и версий ставок. Хранить публичные условия отдельно от персональных предложений и внутренних параметров риска.
- Перенести согласование специальных ставок из почты в рабочий процесс АБС, настроить роли депозитного и кредитного бэк-офисов.
- Добавить интерфейс чтения опубликованных версий ставок и обработки онлайн-заявок. Предусмотреть ключи идемпотентности и ограничение частоты обращений адаптера.
- Подготовить однократную загрузку действующих ставок из Excel и сверку с бизнесом. После запуска прекратить разрозненное редактирование файлов.
- Добавить статусы подтверждения ставки и открытия депозита, которые адаптер сможет передать в контур заявок.

## Контур заявок и интеграции

- Развернуть API заявок и БД MS SQL: заявки, статусы, read model ставок, outbox, история отправок.
- Реализовать обработчик outbox и адаптер АБС с повторами, ограничением нагрузки и журналированием сквозного идентификатора.
- Подключить существующий SMS-шлюз через отдельный компонент банка: одноразовые коды, уведомления о ставке и открытии, защита от повторной отправки.
- Добавить синхронизатор ставок для внутреннего кол-центра и генератор полного файла для партнёра. Оба должны использовать одну опубликованную версию АБС.
- Настроить SFTP-доставку: отдельные учётные данные, выделенный каталог, временное имя файла до завершения передачи, контрольная сумма, повтор после ошибки.
- Добавить мониторинг последней полученной версии, отставания синхронизации и неуспешных доставок.

## Интернет-банк

- Добавить каталог депозитов с общими и персональными ставками, время последнего обновления показывать на экране.
- Реализовать форму со счётом и суммой, SMS-подтверждение через API контура заявок и повторное безопасное отправление формы.
- Показывать статусы обработки и открытия. Не обращаться к новому модулю АБС напрямую.
- Подготовить экраны по дизайн-системе и провести проверку скорости загрузки справочников.

## Сайт

- Получать публичный каталог из API заявок, не хранить отдельную копию ставок в CMS или коде сайта.
- Сделать форму с Ф. И. О. и телефоном, клиентскую и серверную валидацию, защиту от повторной отправки.
- Передавать лид по HTTPS и показывать клиенту результат приёма. Не выводить персональные ставки неавторизованному посетителю.

## Система кол-центра банка

- Принимать лиды с сайта и выводить их в очередь оператора.
- Добавить Rates API и read model публичных ставок в PostgreSQL. Обновление версии должно быть атомарным, чтобы оператор не видел наполовину обновлённый список.
- Добавить экран консультации с действующими условиями и временем последнего обновления.
- Настроить роли операторов, журнал обращений и проверку работы 200 пользователей без прямых вызовов АБС.

## Партнёрский кол-центр

- Согласовать формат полного снимка: продукт, срок, диапазон суммы, ставка, версия и время формирования.
- Проверить загрузку файла во внешнюю систему и процедуру перехода на последнюю версию.
- Обновить скрипты консультации: оператор называет условия из последнего файла и не обещает персональную или специальную ставку.
- Провести пилот с частью операторов и проверить поведение при пропущенной выгрузке.

## Инфраструктура, ИБ и эксплуатация

- Настроить TLS, хранение ключей и SFTP-секретов, сетевой доступ только между необходимыми компонентами.
- Развернуть stateless-сервисы минимум в двух экземплярах, настроить балансировку и резервный ЦОД.
- Проверить разделение данных депозитного и кредитного бэк-офисов, аудит операций и отсутствие чувствительных значений в журналах.
- Подготовить инструкции по повторной обработке заявки, повторной выгрузке файла и переключению ЦОД.
- Выполнить нагрузочные, отказоустойчивые и сквозные проверки до промышленного запуска.
